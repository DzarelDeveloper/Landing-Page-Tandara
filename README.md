# TANDARA Landing Page

Landing page React + Vite untuk TANDARA, sistem kehadiran sekolah yang menghubungkan terminal gerbang, dashboard sekolah, guru, dan orang tua.

## Menjalankan secara lokal

**Prasyarat:** Node.js 20 atau lebih baru.

```bash
npm install
npm run dev
```

Buka `http://localhost:3000` di browser.

## Perintah yang tersedia

- `npm run dev` menjalankan server pengembangan.
- `npm run lint` menjalankan pemeriksaan TypeScript.
- `npm run build` membuat production build.
